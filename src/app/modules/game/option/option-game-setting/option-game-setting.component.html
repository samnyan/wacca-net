ゲーム設定

  • スピード調整
    4.7
    ノーツのスピードを設定できます。
  • 判定調整設定
    +0.0
    入力判定タイミングを設定できます。
  • マスク濃度
    濃度+3
    マスク濃度を設定できます。
  • 背景動画設定
    毎回確認
    プレイ中の背景動画表示を設定できます。
  • ボーナス効果
    OFF
    ボーナスノーツの効果のON/OFFを設定できます。
  • ミラー設定
    なし
    プレイ中のノーツ配置入れ替えを設定できます。
  • ギブアップ設定
    ノータッチ
    プレイ中の「途中終了」を設定できます。
